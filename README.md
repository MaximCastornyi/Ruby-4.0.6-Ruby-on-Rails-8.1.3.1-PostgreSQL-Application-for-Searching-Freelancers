
# Ruby-4.0.6-Ruby-on-Rails-8.1.3.1-PostgreSQL-Application-for-Searching-Freelancers 
This is a freelancer search app with a search function, pagination, order confirmation system, built-in internal chat, admin panel and payment options.
=======
Getting Started

To run this application do next steps:

```bash
rails db:setup
rails db:migrate
```
next
```bash
rails db:seed OR use ___BD_DUMP___.sql file for PostgreSQL DB
```
In the second way use login 'admin@admin.com' and password '123456789'
